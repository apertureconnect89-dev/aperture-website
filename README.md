# APERTURE – Final Project
Documentary storytelling website built with **HTML5, CSS3, JavaScript, and Bootstrap 5.3.3** (loaded from the jsDelivr CDN). Published with GitHub Pages.

## Folder structure
```
Aperture_FinalProject/
├── index.html  stories.html  about.html  community.html  connect.html
├── css/style.css      custom styles (colors at the top)
├── js/script.js       footer year
├── images/            all photos
├── README.md
└── surname_processjournal.pdf   (add before submitting)
```

## Editing (for beginners)
- **Text:** open the .html file in VS Code, Ctrl+F the words, retype, Ctrl+S.
- **Images:** put the photo in `images/`, then change the file name inside `src="images/..."`. Update `alt="..."`.
- **Links:** change what is inside `href="..."`. Search `REPLACE` to find every placeholder.

## Publish on GitHub Pages
1. github.com > New repository (e.g. `aperture`), Public.
2. Add file > Upload files: upload everything INSIDE the project folder (index.html must be at the top level), then Commit.
3. Settings > Pages > Branch: `main`, folder `/ (root)` > Save.
4. After 1–2 minutes: `https://YOUR-USERNAME.github.io/aperture/`
5. Test every link before submitting.
